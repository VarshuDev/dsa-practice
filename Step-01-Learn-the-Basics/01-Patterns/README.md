# Step 1.2: Pattern Problems 📐

Collection of pattern problems from the Striver A2Z DSA sheet to master nested loops and matrix logic.

---

### 💡 Striver's 4 Rules for Any Pattern

1. **Outer loop**: Controls the number of **rows** (usually `i = 0` to `n - 1` or `i = 1` to `n`).
2. **Inner loop**: Connects rows to **columns** (observe how many items are printed for row `i`).
3. **What to print**: Print the character (`*`, number, letter, or space) inside the inner loop without a newline.
4. **End of row**: Print a newline (`cout << endl;`) after the inner loop finishes each row.
